# Instructions for ExoFOP-TESS cTOI Submission

To upload these 3 candidates to ExoFOP (NASA/IPAC):

1. **ExoFOP Account**:
   - Register or sign in at https://exofop.ipac.caltech.edu/tess/
   - Under your user profile, set your User Tag (e.g. `arastogi`).
2. **Bulk Upload**:
   - Go to: https://exofop.ipac.caltech.edu/tess/upload_planet_params.php
   - In the prepared file `params_planet_20261107_001.txt`, replace `[USER_TAG]` with your user tag.
   - Select and upload the file.
3. **Verification**:
   - Check https://exofop.ipac.caltech.edu/tess/view_ctoi.php to verify all 3 candidates are listed as active cTOIs!
